# Visual assets

- `team-universe.png`: original raster scene created with the built-in ImageGen tool for this project. Art direction/prompt: a cinematic charcoal starfield, a dark mineral eclipse/planet left of center with restrained warm amber rim light, rich foreground rock texture and dark negative space at right; preserve the selected entrance composition while removing every UI label, icon, form and watermark. The user supplied igloo.inc as an atmosphere/motion reference; no Igloo scene assets or branding are copied.
- Runtime motion: local star particles and pointer-driven raster parallax, with explicit pause, system reduced-motion and hidden-tab handling. This is not a claim of a full WebGL planet simulation. No audio is implemented.
- `fonts/Manrope.ttf`, `fonts/IBMPlexMono-Regular.ttf`: self-hosted Google Fonts distributions. OFL license texts are included beside the fonts.
- `icons/*.svg`: official Phosphor regular icons. The MIT license is included in `icons/LICENSE`.

The editable UI stays in HTML/JavaScript/CSS; it is not a screenshot with invisible form controls.
